Q. A message has been encrypted using RSA. The public key is gone… but someone might have been careless with the private key. Can you recover it and decrypt the message?
   Download the flag and image.
Hints: 1.Metadata can tell you more than you expect.
       2.Hex can be turned back into a key file.

Level: Easy

Step & Command:
1. cd Download
2. ls
3. file image.jpg
4. exiftool image.jpg
// Find: Comment.
// Decrpyt this use hashes.com and find private key.
5. cat > private
// Paste the key.
6. openssl pkeyutl --decrypt -inkey privatekey -in flag.enc -out flag.txt
7. cat flag.txt
// Finally, I found the flag.
